## 四、验收结论与遗留

### 结论

**v1.2.2 验收通过**：51 项契约功能完整性达标、质量门禁全绿、文档治理后齐套；八线 70/70 E2E + 129/129 IT 双绿，v1.2.2 七项修复全部复验成立，无阻断缺陷。

### 遗留（登记在册，不阻塞验收）

1. **P3×3 展示项**（第 2 轮回归 §四）：未读角标 0 不隐藏 / 订阅页「站内信」恒选列渲染为未勾选 / 投递页无「下次重试」列——均不影响服务端契约，建议随下个前端版本处理；
2. **SMS 渠道**：ADR-0004 引 Sms4J，待有网/私服环境落地（环境约束，非缺陷）；
3. **e2e 边界**：benefit 遗留 spec 已归档 `frontend/legacy/`（物理删除时机待决策）；现行 `frontend/e2e-regression/` 已按 `/nfy/tenant/app/**` 重写并全绿，`l1-auth.spec.ts` 存在 6 处 U+FFFD 坏字节待下轮修字面量；
4. 其余低优登记项详见 `docs/release/delivery-checklist.md` §五（V1.0/V1.2 历史登记与环境复验项）。
