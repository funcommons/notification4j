## 四、本轮新发现（均 P3，登记不修，修复意见如下）

| # | 级别 | 发现 | 修复意见 |
|---|---|---|---|
| 1 | P3 | **未读角标 0 不隐藏**：Long→String 契约下 `unread_count` 为字符串 `"0"`（真值），MessagesPage 赋值后 `:hidden="!unread"` 恒 false；API 类型声明 `number` 掩盖了运行时型别。证据：L2-06-撤回后不再展示.png（空态正确但角标「0」可见） | 赋值处 `Number()` 归一（同页 `parseFwkTime` 先例）；api 类型改 `number \| string` |
| 2 | P3 | **E-L4-02 订阅页「站内信」恒选列渲染为未勾选**（`<el-checkbox model-value disabled>` 空串属性被判假）——与「INAPP 恒选」语义不符；服务端契约不受影响（L4-09 API 断言钉死恒首位）。与第 1 轮 F-3 同源，本轮 UI 图再次确认 | 改 `:model-value="true"` |
| 3 | P3 | **E-L5-02 投递页无「下次重试」列**：退避/静默窗场景 next_retry_at 用户不可见（本轮以 API 证据页补位） | 投递页增「下次重试」列或状态徽标 tooltip |
| 4 | P3（测试资产） | `l1-auth.spec.ts` 存在 6 处 U+FFFD 坏字节（历史文件损伤），致证据文件名带坏字节（本轮产物已重命名规避） | 下轮修 spec 字面量（不改用例语义） |
