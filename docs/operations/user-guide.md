# 用户手册（消息中心）

> 面向终端用户的嵌入式消息中心使用说明。页面以 `frontend/src/views/nfy/` 实际实现为事实源（v1.2.2，五页 + 铃铛）。

## 1. 入口

消息中心由宿主应用（业务方系统）以 iframe 嵌入提供，地址形如 `/nfy/tenant/app/messages`。
打开后自动与宿主完成安全握手（token 只进内存、不落 URL/存储），无需手动登录。
若出现「会话已失效，正在重新连接…」提示，表示登录态已过期，系统正在自动重连，稍候即可；持续失败请联系宿主应用重新进入。

## 2. 五个页面

| 页面 | 入口 | 能做什么 |
|---|---|---|
| **消息** | 侧栏「消息」 | 查看发送给自己的站内信（未读橙色标识/URGENT 红色标识）；按 全部/未读/已读 筛选；点开即自动标记已读；「标为已读」一键处理 |
| **公告** | 侧栏「公告」 | 查看平台级与租户级公告（需确认的公告带确认按钮）；点「标为已读」/「我知道了」完成阅读与确认回执 |
| **渠道** | 侧栏「渠道」 | 自注册 IM 群机器人（钉钉/企业微信/飞书 webhook，仅支持官方域名、443 端口）或邮箱渠道；查看验证状态；验证通过后启用/禁用/删除 |
| **订阅** | 侧栏「订阅」 | 按消息类型 × 渠道勾选接收矩阵（全量保存）；「站内信」为恒选列；部分类型带免打扰时段（quiet_hours，到期自动发出）；带「强制」徽标的类型不可取消 |
| **投递** | 侧栏「投递」 | 按用户/渠道类型/状态查询站外投递记录（状态：待投递/成功/失败/死信）；失败记录可等自动重试或联系管理员人工「重投」 |

## 3. 铃铛（宿主页面角标）

宿主页面可嵌入铃铛单页（`/nfy/tenant/page/bell`）：实时展示未读数角标，下拉显示最近消息，点「查看全部」跳转消息中心。

## 4. 常见问题

| 现象 | 说明 |
|---|---|
| 列表显示「暂无消息」 | 无数据或筛选条件下无匹配；若刚收到消息仍未出现，联系管理员检查发送记录 |
| 渠道注册被拒绝 | webhook 仅接受钉钉/企微/飞书官方域名且 443 端口（防 SSRF）；邮箱需格式合法；错误码 10609/10100 见接口文档 |
| 消息一直未投递到 IM 群 | 查看投递页状态：失败会自动重试（1/5/15 分钟退避，≤3 次）；免打扰时段内的消息在时段结束后发出；渠道连续失败 5 次会熔断停用，需管理员处理 |
| 消息消失 | 该消息可能已被发送方撤回（撤回后列表/详情/未读数均不可见） |
