## 四、发现与修复意见

### ND-L5-01【P1·产品缺陷→✅ 已修复（2026-09-18）】EMAIL 渠道无 API 通路可达 ENABLED

- **现象（修复前）**：EMAIL 渠道 `verify` 恒 10604（提示"首次投递时校验"）；`patch ENABLED` 恒 10610（要求 last_verify_at）；而投递计划与引擎**只认 ENABLED** 渠道 → 纯 API 外发链断裂。IT 因 mapper 直置 ENABLED 未暴露（跨层盲区）。
- **修复**：`ChannelCoreService.patch` EMAIL 豁免 lastVerifyAt 前置 + 熔断态显式重启用即清零（IM 分支不变）；`DeliveryEngine` 投递成功补 `last_verify_at` 置位（对齐 10604 文案自述的「首次投递时校验」语义）。
- **验证**：单测新增 2 例红→绿；IT `NfyChannelFlowTest.email_pending_patch_enabled_succeeds_nd_l5_01` 红→绿；e2e l5 spec 已去 pg-fixup 绕行、改走真实 API 使能（L4|L5 20/20 绿）；全量 IT 127/127 + e2e 70/70 复验。
- **历史证据**：`L5-00-缺陷登记ND-L5-01.png`（L5-00 用例已翻转为修复回归：verify 10604 契约不变 + 直启 code=0）。
